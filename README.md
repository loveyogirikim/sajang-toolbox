# 사장님 업무 도구함

가입 없이 바로 여는 소상공인·소규모 사업장용 무료 업무 도구 21종.

- 사이트: https://sajang-toolbox.vercel.app/
- 홍보·마케팅(가게 카드, 팔리는 한 줄, 상세페이지 조립기, 광고 문구 점검, 홍보 문자, 할인 손익, 카드뉴스), 노무·급여·계약(급여·임금명세서, 근로계약서, 근무표, 상시 근로자 수, 연차·퇴직금·주휴수당, 직원 복무 길잡이, 업무 달력), 행사·모임(가게 안내문, 조 편성)
- 입력한 내용은 브라우저(이 기기)에만 저장되며 서버로 보내지 않습니다.
- AI는 API 키 없이, 도구가 만든 지시문을 사용자가 쓰는 ChatGPT·Claude·Gemini에 붙여 넣는 방식입니다.

## 구조

- `index.html`, `hub.js`, `ui.js`, `style.css` — 첫 화면(도구 찾기·목록)
- `apps/` — 도구별 페이지(HTML)와 화면 스크립트
- `core/` — 도구별 계산·생성 로직
- `data/` — 도구 목록, 노무 요율, 업무 달력, 광고 위험 표현 규칙, 상세페이지 템플릿 등

서버·DB 없는 정적 웹앱이며 Vercel로 배포합니다.

> 계산·안내는 참고용이며 최종 판단은 전문가와 관계 기관에 확인하세요.
